# Decision 0001: Scope of the first serialization

Status: agreed direction for the draft; not yet a released specification.

The ISA-PHM conceptual model is described independently of any particular
serialization. The first fully specified and testable serialization is
ISA-JSON, built on an applicable ISA-JSON baseline that still needs to be
identified and pinned.

ISA-Tab is out of scope for the first specification release. This does not
declare ISA-Tab invalid or incompatible with ISA-PHM. The paper discusses both
ISA-Tab and ISA-JSON; a detailed ISA-Tab mapping and validation can be
considered separately in a future effort.

This decision does not restrict measurement files to CSV, settle the rules
for file paths or pointers into files, or specify how to validate datasets.
Those matters remain open.

# Decision 0012: Diagnostic or prognostic dataset

Status: agreed decision. The specification has not yet been released.

For the first ISA-PHM specification release, a dataset is classified as
either diagnostic or prognostic, not both. Related diagnostic and prognostic
work can be represented as separate datasets.

The exact ISA-JSON field or comment, permitted serialized values, legacy-data
handling, and the detailed study/run rules remain to be specified. This decision
does not imply that a validator can infer the research purpose solely from
measurement files.

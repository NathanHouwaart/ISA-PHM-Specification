# Decision 0014: Review and migration of existing comment conventions

Status: agreed direction for the draft; not yet a released specification.

Review existing ISA-JSON comment names and representations before adopting
them into the shared specification. Preserve existing names where they are
clear and appropriate rather than renaming them solely for consistency.
Where a convention is misleading, unsuitable or conflicts with a preferred
ISA representation, changes should be deliberate and compatibility with
existing datasets and consumers should be documented and considered.

This is a review and migration approach, not blanket approval of every
existing comment or a promise that all current spellings remain unchanged.
Individual fields, case handling, identifier meaning, optionality and legacy
handling still require decisions and tests.
